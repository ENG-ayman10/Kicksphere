# إعداد KickSphere على Render

**الحالة: دليل مُجهّز، ولم يُنفَّذ نشر من خلاله.** بتاريخ 4 أكتوبر 2026 نجح 243 اختبارًا محليًا بعد إضافة أمر تشغيل Render، وفحص اعتمادات الإنتاج سجّل صفر ثغرات مع استبعاد اعتمادات التطوير والاعتمادات الاختيارية. تحديث `@fastify/busboy` إلى `3.2.2` موجود محليًا. رابط خدمة Render الفعلي لم يتأكد بعد.

## 1. تجهيز المصدر والخدمة

انشر آخر ملفات الخلفية المراجعة إلى فرع `codex/professional-foundation` أولًا، ثم اختره في Render. الفرع المحلي الحالي بهذا الاسم؛ `main` البعيد لا يحتوي آخر الإصلاحات. لا ترفع `.env` أو `serviceAccountKey.json` أو `.audit/` أو `uploads/`.

أنشئ **Web Service** من مستودع `ENG-ayman10/Kicksphere`، باستخدام **Node.js** وخطة **Free**. جذر مستودع الخلفية هو مكان `package.json` و`server.js`.

| الإعداد | القيمة |
|---|---|
| Branch | `codex/professional-foundation` بعد وصول آخر المصدر إلى GitHub |
| Build Command | `npm ci --omit=dev --omit=optional --ignore-scripts` |
| Start Command | `node scripts/start-render.js` |
| Health Check Path | `/api/ready` |
| `NODE_VERSION` | `22` |
| `NODE_ENV` | `production` |
| `ENABLE_LIVE_POLLING` | `true` |
| `TRUST_PROXY` | اقتراح أولي: `1`، لكن عدد الوسطاء الحقيقي ما زال يحتاج التحقق على الخدمة قبل النشر؛ لا تستخدم `true` |

ضبط `NODE_VERSION` يمنع اختيار إصدار رئيسي مختلف تلقائيًا. مسار الفحص يؤكد نجاح تهيئة التطبيق، ولا يثبت وحده دقة بيانات الكرة أو وصول الإشعارات. [توثيق إصدار Node.js](https://render.com/docs/node-version)، [توثيق فحص الصحة](https://render.com/docs/health-checks).

## 2. متغيرات البيئة والأسرار

أدخل القيم داخل **Environment** للخدمة؛ لا تضعها في هذا الدليل أو GitHub أو المحادثة. يمكنك استخدام **Save only** عند تجهيز المتغيرات لتجنب نشر إعداد ناقص. [توثيق متغيرات Render](https://render.com/docs/configure-environment-variables).

| المتغير | ما يُضبط |
|---|---|
| `PUBLIC_BASE_URL` | يأخذ أمر التشغيل رابط HTTPS الذي يوفّره Render في `RENDER_EXTERNAL_URL` تلقائيًا؛ يمكن ضبط نطاق فعلي مختلف صراحةً دون `/api` أو مسار إضافي |
| `ALLOWED_ORIGINS` | الافتراضي في أمر Render هو أصل الخادم نفسه فقط. عند نشر الويب اضبط قائمة صريحة بأصول HTTPS المسموح لها، تفصل بينها فواصل. لا تستخدم `*` أو localhost |
| `JWT_SECRET` | نفس السر الحالي من البيئة المحلية للحفاظ على صلاحية جلسات الدخول؛ لا تستبدله بسر جديد خلال النقل |
| `FIREBASE_PROJECT_ID` | مشروع Firebase نفسه المستخدم حاليًا |
| `FIREBASE_CLIENT_EMAIL` | بريد حساب الخدمة من ملف حساب Firebase المحلي |
| `FIREBASE_PRIVATE_KEY` | المفتاح الخاص من حساب الخدمة نفسه؛ يدعم الكود فواصل الأسطر الحقيقية أو `\n` |
| `BSD_API_TOKEN` | مفتاح BSD الحالي داخل مخزن أسرار الخادم |

لا يكفي نسخ `.env` المحلي وحده: Firebase المحلي يعتمد على ملف حساب الخدمة، بينما فحص الإنتاج يشترط المتغيرات الثلاثة أعلاه. تطبيق Android لا يحتاج Origin؛ قائمة CORS تخص المتصفح. لا تُنسخ أصول localhost من إعداد التطوير إلى الإنتاج، ولا يُثبت منفذ محلي بدل `PORT` الذي يوفّره Render.

أمر `start-render.js` مخصص لمنصة Render، ويجري فحص الإنتاج الصارم قبل تشغيل عملية الخادم نفسها. لا يخمّن اسم النطاق ولا يولّد سر دخول جديدًا، ولا يضيف أي أصل ويب خارج القائمة المحددة. [متغيرات Render الافتراضية](https://render.com/docs/environment-variables).

## 3. التحقق بعد النشر الفعلي

بعد ظهور آخر إصدار بحالة **Live**، افحص `/api/health` و`/api/ready` على الرابط الحقيقي، ثم قائمة المباريات وتفاصيل مباراة ونادٍ ولاعب وصورهم. افحص تسجيل الدخول والتفضيلات وتنبيه مباراة حقيقي بصورة منفصلة؛ نجاح health لا يكفي.

بعد نجاح ذلك يُبنى Android برابط API الحقيقي المنتهي بـ`/api` و`KICKSPHERE_ENV=production`، ثم يُثبّت فوق النسخة الحالية للحفاظ على بياناتها. لا تعتمد رابط Render قديمًا أو اسمًا افتراضيًا قبل التأكد من الخدمة الجديدة.

## 4. حدود الخطة المجانية

تنام الخدمة بعد **15 دقيقة دون طلبات واردة**، وقد يحتاج الطلب التالي **نحو دقيقة** لتشغيلها. أثناء النوم تتوقف دورات جلب النتائج وإرسال تنبيهات المباريات؛ لذلك هذه الخطة للتجربة ولا تضمن تنبيهات مستمرة. [قيود Render Free](https://render.com/docs/free#spinning-down-on-idle).

الملفات المحلية تُفقد عند إعادة النشر أو التشغيل أو النوم، ولا تدعم Free قرصًا دائمًا. صور الحساب الحالية في `uploads/avatars` تحتاج تخزينًا دائمًا منفصلًا قبل اعتبارها محفوظة. [الملفات المؤقتة](https://render.com/docs/free#local-files-lost-on-redeploy).

تحظر Free الاتصالات الصادرة إلى منافذ SMTP **25 و465 و587**؛ إرسال استعادة كلمة المرور المعتمد عليها حاليًا لن يعمل بهذه الطريقة، ويحتاج تكامل بريد عبر HTTPS قبل اعتماده. [قيود الاتصال](https://render.com/docs/free#other-limitations).
